How the Detection System Works

The application implements a modular computer vision pipeline built with Python, OpenCV, and Django:

1. Image Upload

Upload any JPG, JPEG or PNG road photo. Client-side preview validates dimensions before transmission.

2. Safe Byte Decoding

File bytes are decoded using NumPy and OpenCV buffer decoding without Windows path or handle errors.

3. Vision Detection

HSV color thresholding, Canny edges, and contour shape geometry detect octagons, circles, and triangles.

4. Result & Meaning

Calculates dynamic processing time, extracts sign meaning and driver action, and stores records in MySQL.
